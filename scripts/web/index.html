Live tmux Claude sessions, branched by working directory. Orch-dispatched sessions hang off orch instead of their directory.

Order matches the tmux picker: waiting → idle → unknown → working, then freshest first. A busy session sinks to the bottom — it is the one to leave alone.
Brightness falls off with idle time: a dim dot has sat untouched for days. Grey dormant sessions have no elapsed time at all — never resumed, so no state hook has ever timestamped them. A working session never dims; its clock counts time busy, not time idle.
